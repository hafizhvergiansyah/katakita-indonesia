# KataKita Indonesia

Permainan susun kata berbahasa Indonesia yang berjalan langsung di browser. Proyek ini terinspirasi oleh tata letak permainan papan kata modern, tetapi menggunakan identitas visual, nama, dan implementasi mandiri.

## Fitur

- Papan 15 x 15 dengan kotak bonus kata dan huruf
- Rak huruf interaktif: pilih, letakkan, acak, dan tarik kembali
- Validasi posisi dasar dan perhitungan poin
- Tampilan responsif untuk desktop dan ponsel
- Antarmuka serta panduan dalam bahasa Indonesia

## Menjalankan lokal

Buka `index.html` di browser, atau jalankan server statis dari folder proyek.
